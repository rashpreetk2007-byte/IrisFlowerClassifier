IRIS FLOWER CLASSIFIER - RASHPREET KAUR ARORA

Put your trained model as:
model.pkl

Put these three real flower images in static/images/:
setosa.jpg
versicolor.jpg
virginica.jpg

Install:
pip install flask numpy joblib scikit-learn

Run:
python app.py

Open:
http://127.0.0.1:5000

Important:
The model predicts from the four numerical measurements. The flower image is displayed after prediction; it is not used for image recognition.
